# XpertDigi Frontend Website

A responsive React and Vite company portfolio frontend inspired by the supplied XpertDigi reference screenshots.

## Included pages

- Home
- About
- Services
- Portfolio
- Blogs listing
- Individual blog article pages
- FAQ with search and accordion
- Contact with dynamic service placeholder and WhatsApp submission

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Replace partner images

Overwrite these files while keeping the same filenames:

- `public/images/team/usman.jpg`
- `public/images/team/mariyum.jpg`

Recommended image size: portrait, at least 900 × 1050 pixels.
